# Orçamento de Honorários AFEARQ

Calculadora de honorários de engenharia e arquitetura pela Tabela de Honorários AFEARQ (REV-2026), com relatório em PDF.

- Tudo em um único arquivo: `index.html`.
- Não usa servidor nem banco de dados: cada profissional usa no próprio navegador.
- Para atualizar índices e valores mínimos, edite o bloco `TABELA (REV-2026)` no início do script em `index.html`.
